# Agent guidance

Every coding agent (Codex, Claude, Cursor, others) follows **`CLAUDE.md`**.
It holds the read map (which file to read when), the repo layout, how to write
Go and tests, how to port a feature, the checks to run before a push, and how
to work with the owner. There is one source of truth so the rules cannot drift.

Feature status and priority: `ROADMAP.md`. Product reasoning:
`docs/maintainers/PRODUCT.md`. Repo layout plan: `docs/maintainers/REPO-LAYOUT.md`.
