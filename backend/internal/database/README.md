# Database schema

Goose migrations live under `migrations/`. The version 1 baseline captures the
current PostgreSQL schema generated by Drizzle (`drizzle/pg`) and includes the
original version 1 Go analytics table. Existing installations that already
record Goose version 1 keep their applied version and do not re-run the baseline;
fresh installations build the Drizzle-owned tables before applying later Go
migrations. The baseline is intentionally a snapshot: do not add feature changes
to it after adoption. Add later Goose migrations instead.

The migration snapshot is sourced from Drizzle PostgreSQL migrations because
legacy tables are shared by the TypeScript application and Go services during
the transition. `drizzle/pg` remains the comparison source until the TypeScript
writer is retired and the schema copy tool has completed.
